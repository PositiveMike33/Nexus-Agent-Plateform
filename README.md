# Agentic Nexus • Architecte Système Agentique

Application web React & Tailwind CSS d'exposition du Portfolio d'Architecte Système Agentique (Pipelines Multi-LLM, Pattern Store, Simulateur d'Orchestration & Calculateur de Potentiel Agentique).

## Fonctionnalités Principales

- **Vision & Philosophie** : Présentation des 3 piliers fondateurs (Micro-Patterns Décomposés, Orchestration Multi-LLM, Garde-fous & Sécurité), des métriques clés et d'une console CLI intégrée interactive.
- **Pattern Store & System Prompts** : Catalogue complet de micro-agents (Analyse, Sécurité, Code, Orchestration) avec prévisualisation et copie directe de prompts système optimisés.
- **Simulateur d'Orchestration Agentique** : Démo interactive en temps réel permettant de configurer un scénario, une stratégie de modèle et des garde-fous pour visualiser le graphe d'exécution à 4 nœuds et les journaux en direct.
- **Études de Cas & Guides Stratégiques** : Retours d'expérience industriels (SecOps Swarm, Enterprise RAG) et documentation opérationnelle (Monétisation AI Studio, Plan STA, Inbound Microservices).
- **Audit ROI & Calculateur Agentique** : Diagnostic interactif selon le domaine, le niveau de confidentialité et le volume pour générer une recommandation d'architecture sur-mesure.
- **Console CLI Modale & Demande d'Audit** : Terminal en ligne de commande (`help`, `patterns`, `arch`, `run`, `clear`) et formulaire de demande de consultation.

## Stack Technique

- **Framework** : React 18 + Vite
- **Language** : TypeScript
- **Styling** : Tailwind CSS v4 + Plus Jakarta Sans & Fira Code
- **Icons & Animation** : Lucide React & Motion
